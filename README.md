# ALSAQQA Steel — موقع مصنع السقا للحديد والصلب

موقع تعريفي لمصنع "السقا للحديد والصلب"، صفحة واحدة (single-page) بالعربية (RTL)، يعرض:

- كتالوج شامل لـ 13 خط منتج (حديد تسليح، زوايا، شراريح، كمرات، صاج، أنابيب، شبك، وغيرها)
- قسم الجودة والمعايير المرجعية (ASTM, DIN, BS, EN)
- القطاعات المخدومة وخط الإنتاج
- نموذج طلب عرض سعر
- بيانات التواصل

## التشغيل

الموقع ملف HTML واحد مستقل (`index.html`) بدون أي اعتمادات خارجية (باستثناء خطوط Google Fonts). يكفي فتحه مباشرة بأي متصفح، أو رفعه على أي استضافة/GitHub Pages ليعمل كموقع كامل.
